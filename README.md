## URLについて

現在、ゲームページの URL を知っている方がアクセスしてプレイできる形で公開しています。

URL の共有範囲については、公開者の意図を尊重してください。

## セーブデータ

ゲームの進行状況や周回情報などは、基本的に各プレイヤーのブラウザの `localStorage` に保存されます。GitHub リポジトリへプレイヤーの進行データが書き込まれる仕組みではありません。

ブラウザのサイトデータを削除すると、保存された進行状況が失われる場合があります。
